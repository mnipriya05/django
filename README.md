# Django Blog Platform

A database-driven blog platform developed using Python and Django.

## Features

- User login and signup
- Create, read, update and delete blog posts
- Blog categories
- Search functionality
- Database integration using Django ORM
- Responsive user interface
- Blog post browsing and detailed post views

## Technologies Used

- Python
- Django
- Django ORM
- SQLite
- Bootstrap
- HTML
- CSS

## Project Structure

- `blog/` - Django application
- `blog_app/` - Main Django project configuration
- `manage.py` - Django project management file
- `db.sqlite3` - Local development database
